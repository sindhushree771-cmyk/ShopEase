# ShopEase – Interactive Product Catalog

## Project Overview
ShopEase is a responsive e-commerce product catalog website that allows users to browse products and filter them by category.

## Features
- Dynamic product display
- Category-based product filtering
- Product details
- Shopping cart functionality
- Add, remove, and update product quantities
- Total price calculation
- Responsive grid layout
- Interactive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Categories
- Electronics
- Clothing
- Home & Decor

## How to Run
1. Download the project ZIP file from this repository.
2. Extract the ZIP file.
3. Open the project folder in Visual Studio Code.
4. Open `index.html` in a browser to view the website.
